# RemoteHand Notes v0.1.0 — Acceptance Record

Date: 2026-10-01

## Result

RemoteHand Notes v0.1.0 was manually accepted on Windows for the planned v0.1.0 scope.

## Accepted behavior

- Plain notes and structured checklists
- Lightweight Markdown
- Autosave and restart persistence
- Pinning and manual ordering
- Search and labels/tags
- Archive and Trash flows
- Note-level lock rules
- Vault auto-lock redaction and unlock reload
- Notes-owned permanent-delete and Empty Trash confirmations
- File attachments stored through RemoteHand Vault blobs
- Image attachments including PNG and WEBP
- Image thumbnail previews and system-open behavior
- Attachment drag-and-drop
- Clipboard image paste
- Attachment reordering and persistence
- Locked-note attachment restrictions
- Attachment removal
- Attachment persistence across full RemoteHand restart
- Attachment cleanup during permanent delete and Empty Trash
- Solid post-it-style card colors and final board UI polish

## Runtime regression fixed during acceptance

Concurrent image previews exposed a Plugin API v1 framing race when multiple panel calls reached a single plugin runtime while the runtime was waiting on nested host API responses. RemoteHand core now serializes each plugin runtime request/response lifetime, and Notes additionally loads image previews sequentially.

## Core dependency

v0.1.0 attachment support requires the RemoteHand core Vault blob API and plugin-runtime serialization changes developed after the existing RemoteHand v1.3.0 tag. The existing v1.3.0 tag remains immutable and is not the release marker for those post-tag core changes.

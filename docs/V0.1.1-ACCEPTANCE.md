# RemoteHand Notes v0.1.1 — Acceptance Record

Date: 2026-10-01

## Result

RemoteHand Notes v0.1.1 promotes the accepted post-v0.1.0 UI/UX polish into the next release baseline.

## Accepted changes

- Responsive Notes toolbar that stays on one line when space allows and adapts cleanly at narrower widths
- Improved editor keyboard flow from Title → Body → Labels/tags, including reverse Shift+Tab navigation for plain notes
- New empty notes/checklists remain transient and are discarded on close when no meaningful content was entered
- Refined sticky-note cards with clipped folded corners and a stronger top-left → bottom-right paper gradient
- New Notes sidebar icon aligned with the sticky-note visual identity
- Card-level image attachment thumbnails
- Non-image attachment document tiles with file-extension labels
- Mixed attachment rows showing up to three actual attachment types
- `+N` overflow indication only for attachments beyond the visible row
- Removal of the redundant bottom paperclip attachment count

## Compatibility

- RemoteHand Plugin API remains v1
- Notes keeps the existing Vault-backed document and blob storage model from v0.1.0
- No note-data migration is required for v0.1.1
- Existing v0.1.0 Notes data remains compatible

## Validation

The functional UI/UX changes were manually exercised on Windows before release preparation. Final v0.1.1 release validation must be performed from the exact intended release commit before the annotated tag is created.

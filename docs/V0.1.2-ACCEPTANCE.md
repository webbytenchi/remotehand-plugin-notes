# RemoteHand Notes v0.1.2 — Acceptance Record

Date: 2026-10-01

## Result

RemoteHand Notes v0.1.2 promotes the accepted Notes board and interaction follow-up work into the next release baseline.

## Accepted changes

- Auto-hiding Notes header so the board can use more of the panel height
- Subtle top-edge down-chevron used only to reveal the hidden header
- Animated header drop-down with delayed auto-hide after pointer/focus leaves the header
- Double-click on genuinely empty board space creates a new plain note
- Sort dropdown preference persists through Notes settings and reload/restart
- Lightweight Markdown preview renders supported syntax correctly after editing
- Markdown headings accept both spaced and compact forms such as `## Heading` and `##Heading`
- Card attachment previews adapt to card width and show as many image/file tiles as fit
- `+N` overflow appears only when additional attachments no longer fit in the row

## Preserved runtime invariant

RemoteHand Notes must not restore the old behavior where a `vault.status` event with `unlocked:true` immediately triggers another `notes.load` while the synchronous `vault.request_access` flow is still completing. The v0.1.2 UI changes preserve the v1.3.1 runtime-framing fix.

## Compatibility

- RemoteHand Plugin API remains v1
- Notes keeps the existing Vault-backed document and blob storage model
- No note-data migration is required
- Existing v0.1.0/v0.1.1 Notes data remains compatible

## Validation

- Rust tests passed: 7/7
- Optimized Windows package build passed
- The updated header behavior and Markdown rendering were manually exercised on Windows
- Papa approved the resulting Notes UX for release preparation on 2026-10-01

Final release validation should be performed from the exact intended v0.1.2 release commit before the annotated tag is created.
